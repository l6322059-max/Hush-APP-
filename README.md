# Hush
Ad-free music player. Plays your own files and searches Audius (full tracks) and iTunes (30 s previews).

## Get the APK
1. Create a GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab, pick **Build APK**, then **Run workflow**.
3. When it finishes, download **hush-debug-apk** from the run page, unzip it and install `app-debug.apk` (allow installs from unknown sources).

Notes: this is a debug-signed APK, fine for personal use. Audio may pause when the app is in the background.
